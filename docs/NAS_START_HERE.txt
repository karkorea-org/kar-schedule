KAR 업무 일정 2.0.2 — Windows NAS 실행용

1. 다운로드와 NAS 준비 (관리자 1명)
GitHub의 비공개 테스트 릴리스 v2.0.2-test.1에서
KAR-Schedule_2.0.2_windows-x64-portable.zip을 받습니다.
ZIP을 먼저 풀고, 안의 KAR Schedule 폴더 전체를 NAS 공유 폴더에 복사합니다.
예: NAS의 공유 프로그램 폴더 안에 KAR Schedule 폴더를 둡니다.
프로그램 폴더는 관리자만 수정하고, 직원은 읽기/실행이 가능하도록 둡니다.
NAS 관리자 메뉴가 필요한 경우 회사에서 사용하는 NAS 관리자에게 요청합니다.
기존 업무 Excel 폴더와 FreeFileSync 설정은 그대로 사용합니다.

2. Windows 노트북에서 첫 실행 (각 PC마다)
파일 탐색기에서 평소 사용하는 NAS 공유 폴더를 엽니다.
KAR Schedule 폴더의 kar-schedule.exe를 더블클릭합니다.
WebView2가 없다는 안내가 나오면 prerequisites 폴더의
WebView2Runtime-x64.exe를 노트북의 다운로드 폴더로 복사해 한 번 설치합니다.
이 파일은 Microsoft의 화면 표시 구성요소 설치 파일입니다.
설치가 끝나면 NAS의 kar-schedule.exe를 다시 실행합니다.
별도 KAR 앱 설치, Node.js, Rust, 서버 설정은 필요 없습니다.
회사 정책이 미서명 앱 또는 NAS 실행을 차단하면 담당자에게 실행 허용을 요청합니다.

3. 업무 파일 연결과 테스트
처음에는 본인 업무 Excel의 테스트 복사본을 노트북 로컬 폴더에 만듭니다.
앱의 Excel 연결에서 그 복사본을 선택하고 일정 시트와 연도를 확인합니다.
업무 하나를 수정하고 Ctrl+S로 저장합니다.
앱을 닫았다가 다시 열어 수정 내용을 확인하고, Excel에서도 확인합니다.
이상이 없으면 Excel에서 파일을 닫고 앱에서 평소 쓰는 본인의 로컬 업무 Excel을 연결합니다.
이후 작성 → Ctrl+S → 저장 완료 확인 → FreeFileSync로 NAS 동기화 순서로 사용합니다.
공유된 최신 내용을 다른 직원이 보려면 NAS의 Excel을 자기 PC로 동기화한 뒤 다시 엽니다.

4. 바탕화면 바로가기
NAS의 kar-schedule.exe를 우클릭해 바탕화면 바로가기를 만듭니다.
Windows 11에서는 추가 옵션 표시 → 보내기 → 바탕화면(바로가기 만들기)을 사용할 수 있습니다.
폴더 경로와 실행 파일 이름을 유지하면 업데이트 후에도 같은 바로가기를 사용합니다.
실행 시 NAS에 연결되어 있어야 합니다.

5. 업데이트 (관리자 1명)
새 버전을 테스트한 뒤 모든 사용자에게 앱을 종료하도록 안내합니다.
기존 NAS의 KAR Schedule 폴더를 이전 버전 보관 폴더로 복사합니다.
실행 경로와 파일 이름을 유지하며 새 패키지의 내용으로 교체합니다.
직원들은 기존 바로가기로 다시 실행합니다.
저장 구조가 바뀌는 업데이트는 제공된 데이터 이전/백업 안내를 먼저 따릅니다.

데이터 위치
SQLite: 각 PC 사용자 계정의 AppData/Roaming/kr.kar.schedule 폴더
화면 캐시: 각 PC 사용자 계정의 AppData/Local/kr.kar.schedule 폴더
업무 공유: 각자의 로컬 Excel과 NAS에 동기화된 Excel
이 패키지에는 개인 업무 Excel이나 기존 SQLite가 없습니다.
여기서 포터블은 앱 설치 없이 실행한다는 의미이며, 작업 데이터는 PC별로 보관됩니다.
SQLite와 화면 캐시를 NAS의 프로그램 폴더로 옮기지 않습니다.

이 패키지는 Windows 10/11 x64용입니다. Mac에서 .exe를 실행할 수는 없습니다.
회사 NAS와 노트북에서 실제 실행·저장·동기화 확인은 위 순서로 진행하세요.
