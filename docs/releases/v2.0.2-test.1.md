Windows 10/11 x64용 KAR 업무 일정 2.0.2 테스트 배포입니다.

**NAS에서 바로 실행하려면 Assets의 `KAR-Schedule_2.0.2_windows-x64-portable.zip`을 받으세요.**

1. ZIP을 풀고 안의 **KAR Schedule 폴더 전체**를 NAS의 공유 프로그램 폴더에 복사합니다.
2. Windows 노트북에서 NAS 폴더를 열고 **kar-schedule.exe**를 실행합니다. 바탕화면 바로가기를 만들면 이후에도 같은 위치로 실행할 수 있습니다.
3. **Excel 연결**로 본인의 로컬 업무 Excel을 선택합니다. 처음에는 테스트 복사본으로 확인하세요.
4. 작성 후 **Ctrl+S → 저장 완료 확인 → FreeFileSync 동기화** 순서로 사용합니다.

WebView2가 없다는 안내가 나오면 ZIP에 포함된 `prerequisites/WebView2Runtime-x64.exe`를 노트북으로 복사해 한 번 설치합니다. KAR 앱 자체를 설치하거나 개발 도구를 설치할 필요는 없습니다. 작업 데이터는 각 PC에 보관되며 프로그램 폴더에 함께 저장하지 않습니다.

[NAS 세팅과 첫 실행 상세 안내](https://github.com/karkorea-org/kar-schedule/blob/main/docs/NAS_START_HERE.txt)

Windows 테스트 환경에서 로컬 폴더 실행, **읽기 전용 SMB 공유 경로 실행**, 로컬 SQLite 생성, 프로그램 폴더 파일 불변을 확인했습니다. [포터블 실행 검증](https://github.com/karkorea-org/kar-schedule/actions/runs/34091445097). 회사 NAS와 실제 노트북의 보안 정책·연결·Excel 저장 및 FreeFileSync 동기화는 안내 순서에 따라 확인하세요. 코드 서명 전 테스트 배포입니다.

PC에 설치해서 사용하려면 기존 `KAR-Schedule_2.0.2_windows-x64-setup.exe`를 선택하면 됩니다. 설치형과 NAS 실행형은 같은 앱 2.0.2이며 개인 업무 Excel이나 기존 SQLite를 포함하지 않습니다.

[원본 Windows 빌드](https://github.com/karkorea-org/kar-schedule/actions/runs/34085783484)에서 TypeScript 테스트 20개와 Rust 테스트 5개가 통과했습니다. 개인 원본 Excel이 필요한 추가 테스트 2개는 CI에서 건너뛰었습니다. ZIP은 검증된 설치 파일에서 동일한 실행 파일과 Microsoft 서명이 유효한 WebView2 구성요소를 추출해 만들었습니다.
