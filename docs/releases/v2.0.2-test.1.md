Windows 10/11 x64에서 테스트할 수 있는 KAR 업무 일정 2.0.2 설치 파일입니다.

1. 아래 Assets에서 `KAR-Schedule_2.0.2_windows-x64-setup.exe`를 다운로드하고 실행합니다.
2. 설치 후 시작 메뉴에서 **KAR Schedule**을 실행합니다.
3. **Excel 연결**로 노트북에 있는 본인 업무 일지 `.xlsx`를 선택합니다.
4. 수정 후 **저장 / Ctrl+S**로 같은 Excel에 저장하고, FreeFileSync로 NAS에 동기화합니다.

Node.js, Rust, 별도 서버는 사용자 PC에 설치하지 않아도 됩니다. WebView2 오프라인 설치 패키지를 포함합니다. 개인 업무 Excel과 로컬 SQLite 데이터는 배포 파일에 포함되지 않으며, 새 PC는 빈 일정으로 시작합니다.

처음에는 테스트용 Excel 복사본으로 저장과 다시 열기를 확인하세요. Windows 코드 서명 전 테스트 빌드이며, 노트북에서의 실제 설치·화면 조작·오프라인 첫 실행 확인은 남아 있습니다.

빌드와 자동 테스트: [GitHub Actions](https://github.com/karkorea-org/kar-schedule/actions/runs/34085783484). TypeScript 테스트 20개 및 Rust 테스트 5개를 통과했습니다. 개인 원본 Excel이 필요한 추가 테스트 2개는 CI에서 건너뛰었습니다.
