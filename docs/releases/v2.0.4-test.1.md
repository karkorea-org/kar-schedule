# KAR 업무 일정 2.0.4

Excel을 열 때 세부 내용 메모가 표를 덮지 않도록 기본 표시를 숨겼습니다. 세부 내용은 파일에 그대로 남으며, Excel에서 셀에 마우스를 올리거나 메모 표시 기능으로 확인할 수 있습니다. 앱의 세부 내용도 그대로 유지됩니다.

월별 요일 칸에 `1(화)`, `2(수)`처럼 일자를 함께 표시합니다. 상단 1~31일, 업무의 날짜 열, 행 배치와 병합 구조는 유지합니다.

## 기존 사용자 업데이트

1. 입력 중인 업무를 저장하고 KAR Schedule을 종료합니다. NAS의 프로그램을 교체한다면 사용 중인 직원들도 앱을 종료한 뒤 교체합니다.
2. 설치형은 새 `windows-x64-setup.exe`를 실행해 업데이트합니다. NAS 실행형은 새 `windows-x64-portable.zip`을 풀어 기존 프로그램 경로와 실행 파일명을 유지하며 교체합니다. Mac은 새 `.dmg`의 앱으로 교체합니다.
3. 앱을 실행해 하단 버전이 **2.0.4**인지 확인합니다. 기존 일정과 연결된 Excel 파일을 그대로 사용합니다. 초기화나 Excel 재연결, FreeFileSync 재설정은 필요하지 않습니다.
4. 연결된 Excel이 Excel 프로그램에서 닫혀 있는 상태에서 **저장 / Ctrl+S / ⌘S**를 누르면 기존 파일에도 새 표시가 적용됩니다. 업데이트 설치 자체는 업무 Excel을 변경하지 않습니다.

SQLite 구조, 앱 식별자, 데이터 저장 위치, 연결 설정 형식, 외부 파일 변경 및 파일 잠금 검사는 변경하지 않았습니다. 이 배포 파일에 개인 업무 Excel이나 기존 DB는 포함하지 않습니다.

이전 버전으로 다시 저장하면 메모와 요일의 표시가 이전 방식으로 돌아올 수 있습니다. 같은 파일을 앱에서 편집하는 사용자는 버전을 맞춰 주세요. Excel만 사용하는 직원은 KAR 앱을 설치하거나 새로 설정할 필요가 없습니다.

검증 범위: 이전 버전의 가상 업무일지 읽기와 반복 저장, 한글·여러 줄 세부 내용 보존, 색상·완료·행 배치 보존, 연말·연초 및 윤년 날짜 표시, 다른 시트 보존, Windows 로컬·읽기 전용 SMB 실행과 기존 DB·연결 정보 보존. 메모 상자의 기본 숨김은 Excel 파일의 표시 설정으로 저장되며, Excel에서 사용자가 직접 ‘모든 메모 표시’를 선택하면 메모가 나타날 수 있습니다.

Mac에서는 2.0.3에서 2.0.4로 앱을 교체하고 기존 데이터·연결 유지 및 ⌘S 저장을 확인했습니다. Excel 본창에서의 실제 화면 확인은 이 Mac의 파일 선택창에서 ‘열기’가 비활성화되어 완료하지 못했으며, Windows Excel 화면도 직접 확인하지 않았습니다. 자세한 결과는 [검증 기록](https://github.com/karkorea-org/kar-schedule/blob/main/docs/V2_0_4_VERIFICATION.md)을 참고하세요.
