# KAR 업무 일정 2.0.3

새로 만든 빈 Excel을 불러올 수 없던 문제를 수정했습니다.

1. Excel에서 내용이 없는 새 `.xlsx` 파일을 만들고 저장한 뒤 닫습니다.
2. KAR Schedule의 **Excel 연결**에서 그 파일을 선택합니다. **더 보기 → Excel 가져오기**로 선택해도 빈 파일이면 연결 화면을 엽니다.
3. 업무일지 연도를 확인하고 **빈 파일 연결**을 누릅니다.
4. **저장 / Ctrl+S / ⌘S**를 누르면 선택한 시트에 해당 연도의 1~12월 양식이 만들어집니다.
5. 업무를 작성하고 저장합니다. 이 Excel을 기존처럼 FreeFileSync로 NAS에 동기화하면 됩니다.

이미 앱에 다른 일정이 있으면 연결 전에 교체 여부를 확인합니다. 빈 파일을 선택하거나 연결한 것만으로 Excel 파일이 바뀌지는 않습니다. 연결한 뒤 처음 저장하기 전에는 ‘Excel 저장 필요’로 표시됩니다.

연도 없는 기존 일정표는 선택한 기준 연도로 읽으며, 연도 안내를 오류와 구분했습니다. 읽지 못한 업무 셀이 있는 경우에는 일부 업무만 연결하거나 원본에 덮어쓰지 않도록 차단했습니다. 기존 파일의 모든 병합 형식을 새로 지원하는 변경은 아닙니다. 일반 표, 메모·수식·개체가 있는 시트를 빈 업무일지로 변환하지 않습니다.

Windows 설치형은 `windows-x64-setup.exe`, NAS 실행용은 `windows-x64-portable.zip`입니다. NAS 실행용은 기존 앱을 모두 종료한 후 새 폴더에 압축을 풀고 실행 파일을 교체하거나 바로가기 대상을 변경하세요. 개인 Excel과 PC의 기존 일정 데이터는 설치 파일에 포함되지 않습니다.

검증: 빈 Excel의 연도 검증·연결·Ctrl+S 저장 화면 테스트, 윤년 업무 저장, 12개월 빈 양식 유지, 다른 시트 보존, 읽기 누락 시 저장 차단, 기존 연결 정보 호환, 외부 변경 및 Excel 잠금 검사. Windows NAS 패키지는 실제 로컬 실행과 읽기 전용 SMB 경로 실행 검증을 통과한 뒤 게시합니다.
