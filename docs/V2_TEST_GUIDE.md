# V2 테스트 안내 — 2.0.2

## 실행

프로젝트의 `outputs/KAR Schedule 2.0.2.app`을 더블클릭합니다. 현재 제공 파일은 Apple Silicon Mac용입니다. 자주 사용하면 응용 프로그램 폴더로 복사하세요. `outputs/KAR Schedule_2.0.2_aarch64.dmg`도 제공합니다. 개발 서버·Node·Rust·Excel 설치 없이 앱을 실행할 수 있습니다.

이 앱은 ad-hoc 서명한 테스트 빌드입니다. 다른 PC에 정식 배포하기 위한 Developer ID 서명·공증과 Windows/Intel 실기 시험은 아직 완료되지 않았습니다.

## 평소에는 연결 → 작성 → 저장

1. 상단 **Excel 연결**을 누르고, FreeFileSync 동기화 대상인 **로컬 폴더의 본인 업무 `.xlsx`**를 선택합니다.
2. 일정 시트와 기준 연도, 업무 수를 확인하고 연결합니다. 파일의 일정을 앱으로 불러옵니다. 내용이 같거나 처음 연결할 때에는 추가 확인 없이 연결합니다. 기존 앱 일정과 내용이 다르면 “현재 일정을 파일 내용으로 바꿀까요?”라고 확인합니다. 복구 사본은 앱이 자동 관리하며 별도 안내를 띄우지 않습니다. 이 단계에서는 Excel을 쓰지 않습니다.
3. 업무를 작성·수정하고 **저장**을 누릅니다. 연결된 Excel의 **같은 경로·같은 파일명**에 반영됩니다. **Ctrl+S / ⌘S**도 동일하게 동작합니다.
4. FreeFileSync는 기존 설정대로 이 로컬 Excel을 NAS로 동기화합니다. 앱은 FreeFileSync를 실행하거나 NAS 동기화 완료 여부를 판단하지 않습니다.

연결 파일은 앱 재실행 후에도 유지됩니다. 다른 직원의 파일을 함께 연결하는 방식은 아니며, 한 번에 본인 파일 하나를 연결합니다. 다른 파일을 선택하면 새 파일의 일정으로 바뀌므로 필요한 현재 일정은 먼저 백업하세요.

## 저장 버튼과 표시 상태

- 업무 입력창의 **저장** 또는 **Ctrl+S / ⌘S**: 입력 내용을 로컬에 저장한 뒤 연결 Excel에도 반영합니다.
- 업무 입력창의 **X**: 입력 중인 수정은 버립니다.
- 바 드래그·업무 삭제·팔레트 변경: 로컬에 먼저 보관합니다. 상단 **저장** 또는 단축키로 Excel에 반영합니다.
- **Excel 저장 필요 · 파일명**: 로컬에는 보관됐지만 연결 Excel에 아직 반영하지 않은 변경이 있습니다.
- **저장됨 · 파일명**: 앱이 마지막으로 읽거나 저장한 파일과 로컬 revision이 일치합니다. 외부 변경은 다음 저장 직전에 검사합니다. NAS 동기화 완료 표시가 아닙니다.
- Excel 미연결 상태에서도 로컬 저장은 됩니다. 파일에 반영하려면 먼저 연결하세요.

저장 중에는 반복 클릭과 단축키 중복 실행을 막습니다. 모달 입력을 로컬에 저장한 뒤 Excel 쓰기가 실패하면 로컬 내용은 남으며, 문제를 해결한 후 상단 저장으로 다시 시도할 수 있습니다.

## Excel 보존과 외부 변경

연결 저장은 **선택한 일정 시트 전체와 ColorDB**를 업데이트합니다. 다른 시트의 XML·수식·메모·관계, 원본 테마/이미지 등은 보존하고 새 스타일을 기존 스타일 인덱스 뒤에 병합합니다. 계산 캐시는 갱신하고 Excel이 다음에 열릴 때 재계산하도록 표시합니다. 선택 일정 시트 자체는 앱의 월간 표로 다시 작성되므로 그 시트의 임의 수식·장식·별도 표는 보존 대상이 아닙니다.

저장 직전에 이전 파일을 앱 데이터의 `backups/excel` 폴더에 최대 10개 보관합니다. 같은 디렉터리에 임시 파일을 완성한 뒤 교체하므로 FreeFileSync가 작성 중인 대상 파일을 읽을 가능성을 줄입니다. FreeFileSync에서 임시 파일까지 동기화하도록 구성했다면 해당 임시 파일 제외 설정도 확인하세요.

Excel에서 파일을 열어 잠금 파일이 남아 있으면 닫은 뒤 저장하세요. Excel 또는 FreeFileSync가 파일을 변경했다면 덮어쓰지 않고 오류를 알립니다. **더 보기 → 백업**으로 현재 앱 일정을 보관하고, 변경된 Excel을 다시 연결하여 내용을 확인하세요. 자동 병합이나 강제 덮어쓰기는 제공하지 않습니다. 파일 교체 직전/직후에 변경을 다시 검사하지만 별도 프로그램과 파일을 동시에 편집하는 분산 잠금 기능은 아닙니다.

## 더 보기

- **다른 이름으로 내보내기:** 새 일정 보고서 `.xlsx`를 만듭니다. 연결된 원본 전체의 복사본을 만드는 기능은 아닙니다.
- **다른 Excel 일정 추가:** 다른 파일에서 업무를 가져옵니다. 현재 연결은 유지되며, 다음 저장 시 합쳐진 일정이 연결 파일에 반영됩니다. 같은 파일을 반복 추가하면 중복될 수 있습니다.
- **백업 / 복원:** ID·전체 기간·월별 행·메모·팔레트를 JSON으로 보관/복원합니다. JSON에 로컬 연결 경로는 넣지 않습니다. 다른 PC에서는 Excel을 별도로 연결하세요.
- **Excel 연결 해제:** 일정과 Excel 파일은 유지하고 저장 대상 연결만 해제합니다.
- **자동 복구 사본 복원:** 교체/초기화 직전 `.db` 사본의 일정을 복원합니다. 현재 연결은 그대로이며, Excel은 다음 저장 때 반영됩니다.
- **V1 JSON 가져오기, 저장 위치 확인, 전체 일정 초기화:** 기존 관리 기능입니다. 초기화 후에도 Excel은 저장 버튼을 누르기 전에는 바뀌지 않습니다.

macOS의 로컬 DB는 `~/Library/Application Support/kr.kar.schedule/kar-schedule.sqlite3`에 있습니다. 실행 중인 DB를 NAS나 FreeFileSync 대상에 직접 두지 말고 공유 Excel과 JSON 백업을 동기화하세요.

## 추천 확인 순서

처음에는 본인 Excel의 **사본**으로 확인하세요. 연결 → 제목/색 수정 → Ctrl+S 또는 ⌘S → Excel을 열어 반영 확인 → Excel 닫기 → 앱 재실행 후 연결 유지 → 드래그 후 저장 → 백업/복원 순서로 테스트할 수 있습니다. 앱의 자동 테스트와 실제 QA에서는 사용자 원본 파일을 변경하지 않았습니다.

`outputs/테스트 일정.json`은 개인정보 없는 샘플입니다. 복원은 기존 앱 일정을 교체합니다. 연결된 업무 파일이 있으면 다음 저장 때 샘플이 들어가므로, 샘플을 시험하기 전 연결을 해제하거나 테스트 Excel을 연결하세요.
